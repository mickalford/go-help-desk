# Project Roadmap

This document outlines the future features, ideas, and planned improvements for the OpsMuster project.

## Planned Features

### 1. Kanban View
- **Description:** Implement a visual drag-and-drop Kanban board for tickets.
- **Goal:** Allow staff to visualize ticket workflows, easily update statuses by dragging cards between columns, and get a high-level overview of active work.

### 2. Client Reports
- **Description:** Generate and send monthly reports to customers/clients.
- **Goal:** Provide clients with a recurring breakdown of ticket volumes, resolution times, and SLA compliance to demonstrate value and keep them informed.

## Under Consideration

### 1. Optional CTI (Category, Type, Item)
- **Description:** Make the strict CTI classification optional when creating tickets.
- **Goal:** Allow for a more flexible "inbox-style" triage workflow where tickets can be created rapidly without predefined categorization. *(Note: Requires deep database and strong-typing updates across the Go and React stacks).*
